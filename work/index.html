Open source

pi packages

Extensions for pi, the terminal coding agent I work in every day.

  • pi-chassis

    v0.4.0

    A workbench for pi. Build and Plan modes, a sidebar and home screen, a git diff view, and git commands that draft commit messages and pull requests.

  • pi-retainer

    v0.4.0

    Persistent memory for pi. The agent saves decisions, preferences and gotchas as it works, and the next session starts with a short index of them. Everything stays in one SQLite file on your machine.

  • pi-governor

    In design

    A guard layer for pi tool calls. One place to decide which calls the agent may make, which need your approval, and which are never allowed.

Other projects

  • Hitch CI

    In design

    An agent-driven CI/CD system. Deterministic pipelines decide pass or fail; agents read failures, propose fixes, judge release risk and watch rollouts around them.

Consulting

I help engineering teams build a culture of efficiency with AI. It’s a smaller shift than most teams expect: agents can be fitted to the tools and workflows you already have, so nobody has to change how they work. Context switching gets close to free, and output goes up without burning people out.

Doing that safely is the hard part, and it’s what I’m good at: agents that work inside your platform’s rules, with engineers reviewing and steering, not rubber-stamping. The work tends to look like this:

  • Mapping AI to your engineers’ existing workflow, with guardrails and habits people keep using.
  • Paying down tech debt fast, without building or migrating to new tools and systems.
  • Building internal tools and extensions so agents can reach your platform safely.
  • Rethinking platform engineering for a world where agents are users of your platform too.

I take on a small number of engagements, usually through referrals, so I can’t say yes to everything. If it sounds like a fit, email me with a few lines about your team and where you are today.
